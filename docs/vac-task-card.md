# VAC 任務規格：簡報轉雙人解說影片

## 目標與輸入

將確認過的 PDF 逐頁轉成教學影片。輸入包括 PDF、Logo、受眾、播放情境、指定聲線、允許修改範圍及交付需求。未提供的事實不得自行補入稿件。

## 執行規格

| 步驟 | 工作與工具角色 | 交付與通過條件 |
|---|---|---|
| 1 素材整理 | PDF 轉圖工具 | 頁碼連續的 PNG，頁數與原檔一致 |
| 2 內容查核 | textbook-check 方法與必要來源查核 | 逐頁錯字、圖文、術語、依據紀錄；存修訂版 |
| 3 雙人稿 | Agent 撰稿 | 女主持人 HsiaoChen 提問，男主講人 YunJhe 解說；每段對應頁碼 |
| 4 分段配音 | edge-tts | 每段可完整解碼；記錄實際聲線與速度；成功片段快取 |
| 5 字幕校時 | TTS 時間資訊與字幕處理 | SRT 對應實際音檔，無逆序與重疊；句界內估時需標明 |
| 6 畫面排版 | 字幕樣式與品牌配置 | 字幕與主內容分區，Logo 不遮住資訊；先看樣片 |
| 7 轉場合成 | FFmpeg | 畫面、音訊、字幕對齊；淡化轉場不截斷解說 |
| 8 驗收交付 | ffprobe、FFmpeg、人工播放 | 技術檢查及實際播放都記錄，問題修正後重驗 |

## 本案例設定

- 女聲 HsiaoChen、男聲 YunJhe；實際可用性由執行環境確認，不能默默換聲線。
- 影片 1920×1080、30fps、H.264/AAC。
- 本案例採底部 220px 獨立字幕區；每行最多16字、最多兩行、白字黑邊。這是案例參數，不是所有教室都適用的保證。
- 轉場採平順淡化，保持閱讀時間。若轉場使用重疊片段，要同步計算音訊與字幕時間偏移。
- 公司 Logo 右上、頁碼右下、完整署名底部；署名兩行時第一行末尾不加分隔符。

## 失敗處理

同一段最多自動嘗試3次，每次記錄原因；仍失敗就停止該段並回報，不無限重試。可先檢查連線、文本長度及設定。調整語速後重算時間軸並試聽，不沿用舊字幕時間。此重試上限是本專案交辦規則，並非案例歷史嘗試次數。

## 輸出

MP4、完整 MP3、SRT、逐頁修訂圖、雙人解說稿、時間軸及驗收紀錄。保存環境版本與字型資訊，方便下一次重製。
