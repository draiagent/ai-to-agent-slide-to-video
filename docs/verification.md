# 檢查、修正、再驗證

## 三個關卡

1. 內容關：PDF、圖片、解說稿及字幕一致；有來源的主張可追溯。不確定處先標記，不能用流暢語句掩蓋疑點。
2. 技術關：音檔非空且可解碼，字幕時間單調、無重疊，影片完整解碼成功。
3. 使用關：試聽專有名詞、檢查轉場與字幕，於預計使用的教室設備播放；後排也要能閱讀。

## 本案例修正

| 發現 | 修正 | 再驗證 |

| 男聲回傳空音檔 | 分段重試，保留成功片段；部分段落調整語速 | 重新測量音長、解碼並建立時間軸 |

## 技術檢查命令（需自行安裝相應工具）

```bash
ffprobe -v error -show_entries format=duration:stream=codec_name,width,height,r_frame_rate -of json output.mp4
ffmpeg -v error -i output.mp4 -f null -
```

這些命令檢查媒體資訊與解碼；無法證明內容正確、字幕易讀或發音自然。本次文件整理未重新執行這兩個影片命令。

## 時間資訊的界線

案例使用 TTS 字詞或句界時間，句界內按文字長度分配字幕時間，未完成人工逐字聽校。因此應稱「依實際配音時間製作字幕」，不能宣稱每個字均精準對齊。使用者確認整體課堂播放可用，不等同逐字校驗。
